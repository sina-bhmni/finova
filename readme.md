# FINOVA - سیستم مدیریت مالی شخصی

FINOVA یک وب‌اپلیکیشن مدیریت مالی شخصی است که با PHP خام (معماری MVC سفارشی)، MySQL و جاوااسکریپت ساخته شده است. این پروژه به کاربر امکان می‌دهد درآمدها و هزینه‌های خود را ثبت کند، چند کیف‌پول یا حساب بانکی مدیریت کند، برای دسته‌بندی‌های مختلف بودجه تعریف کند، برای اهداف مالی خود پس‌انداز کند و گزارش‌های تحلیلی از وضعیت مالی خود دریافت کند.

## امکانات

### مدیریت کاربران
- ثبت‌نام و ورود با احراز هویت مبتنی بر Session
- هش کردن رمز عبور با bcrypt
- محافظت CSRF روی تمام فرم‌ها
- ویرایش پروفایل و تغییر رمز عبور

### مدیریت مالی
- ثبت تراکنش از سه نوع: درآمد، هزینه، انتقال بین حساب‌ها
- مدیریت چند کیف‌پول/حساب بانکی با محاسبه خودکار موجودی
- دسته‌بندی قابل‌تنظیم برای درآمد و هزینه
- جستجو، فیلتر چندگانه و صفحه‌بندی در لیست تراکنش‌ها

### بودجه و اهداف
- تعریف بودجه ماهانه برای هر دسته‌بندی هزینه
- محاسبه درصد مصرف واقعی بودجه بر اساس تراکنش‌ها و نمایش هشدار در آستانه سقف
- تعریف اهداف مالی با مبلغ هدف، مهلت زمانی و پیگیری میزان پیشرفت

### داشبورد و گزارش‌گیری
- نمایش خلاصه وضعیت مالی (موجودی کل، درآمد، هزینه، پس‌انداز ماه جاری)
- نمودار روند درآمد و هزینه در ماه‌های اخیر
- نمودار تفکیک هزینه‌ها بر اساس دسته‌بندی
- گزارش مالی با بازه زمانی دلخواه و مقایسه با دوره قبل

### سایر امکانات
- اعلان‌های داخلی (نزدیک شدن به سقف بودجه، ثبت درآمد، رسیدن به هدف مالی)
- ثبت لاگ فعالیت کاربران
- پنل مدیریت برای کاربران با نقش ادمین (آمار کلی، لیست کاربران، لاگ فعالیت سیستم)
- طراحی واکنش‌گرا (Desktop، Tablet، Mobile)

## فناوری‌های استفاده‌شده

| بخش | فناوری |
|---|---|
| Backend | PHP (بدون فریم‌ورک، معماری MVC سفارشی) |
| پایگاه داده | MySQL (با PDO و Prepared Statements) |
| Frontend | HTML5، CSS3، JavaScript خالص |
| نمودار | Chart.js |
| احراز هویت | Session + bcrypt |
| امنیت | CSRF Token، Input Validation، Prepared Statements |

## ساختار پروژه

```
finova/
├── app/
│   ├── controllers/     کنترلرهای برنامه
│   ├── models/          مدل‌های ارتباط با دیتابیس
│   ├── services/        لایه منطق تجاری (تراکنش، بودجه، گزارش، انتقال)
│   ├── views/            فایل‌های نمایش (View)
│   └── helpers/          توابع کمکی (احراز هویت، CSRF، اعتبارسنجی)
├── config/               تنظیمات برنامه و اتصال دیتابیس
├── database/
│   ├── schema.sql        اسکریپت ساخت جداول
│   └── seed.sql          داده‌های نمونه برای تست
├── public/
│   ├── css/              فایل‌های استایل
│   ├── js/               فایل‌های جاوااسکریپت
│   └── index.php         نقطه ورود اصلی برنامه
├── routes/
│   └── web.php           مسیریابی برنامه
└── index.php             هدایت خودکار به داخل برنامه
```

## نصب و راه‌اندازی

### پیش‌نیازها
- PHP نسخه ۸ یا بالاتر (با افزونه‌های pdo_mysql و mbstring فعال)
- MySQL یا MariaDB
- یک سرور محلی مانند XAMPP، Laragon یا WAMP

### مراحل نصب

۱. پوشه پروژه را در مسیر htdocs (یا www) سرور محلی خود قرار دهید.

۲. یک دیتابیس جدید بسازید و اسکریپت ساخت جداول را اجرا کنید:

```
mysql -u root -p < database/schema.sql
```

۳. در صورت نیاز به داده‌های نمونه برای تست سریع، اسکریپت زیر را نیز اجرا کنید:

```
mysql -u root -p finova_db < database/seed.sql
```

۴. در فایل `config/config.php` اطلاعات اتصال به دیتابیس (نام کاربری، رمز عبور، نام دیتابیس) را در صورت نیاز تنظیم کنید.

۵. آدرس پروژه را در مرورگر باز کنید. برنامه به‌صورت خودکار به صفحه ورود هدایت می‌شود.

### ورود با داده‌های نمونه

اگر فایل `seed.sql` را اجرا کرده‌اید، می‌توانید با این اطلاعات وارد شوید:

```
ایمیل:      admin@admin.com
رمز عبور:   admin
```
